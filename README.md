# Pennywise Expense Tracker

A responsive expense tracker built with standalone Angular components. Add expenses with a description, amount, category, date, and optional note; search and filter the list; and edit or delete existing entries. The overview summarizes spending and transaction counts for the current month.

Expenses are stored in this browser's local storage, so they persist across reloads on the same device. Amounts are displayed in Indian rupees (INR).

## Development

Install dependencies with `npm install`, then start the development server:

```bash
npm start
```

Open `http://localhost:4200/`. To build the application, run `npm run build`. To run unit tests, run `npm test`.
